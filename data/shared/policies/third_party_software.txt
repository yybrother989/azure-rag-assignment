THIRD-PARTY SOFTWARE INSTALLATION POLICY
Effective 2024-09-01. Owner: IT Security.

Q: Are employees allowed to install third-party software on company laptops?

A: Conditionally yes, but with constraints. See sections 1-3.

1. Approved software list
Employees may install any software listed on the IT-Approved Catalog
(internal portal: it/catalog) WITHOUT a ticket. The catalog is reviewed
weekly by IT Security and currently contains ~120 vetted applications
including Slack, Zoom, the JetBrains suite, VS Code, and the major
browsers.

2. Off-catalog software
Software not on the catalog requires a ticket to IT Security via the
"Software Request" form. Each request is reviewed against:

   2.1 License compatibility (no AGPL or SSPL on company endpoints).
   2.2 Vendor reputation and recent CVE history.
   2.3 Data egress posture — the requester must declare whether the
       software phones home and to which destination.
   2.4 Endpoint hygiene — the software must not disable the EDR agent.

Typical turnaround on an off-catalog request is 2-3 business days.

3. Strictly forbidden categories
Regardless of vendor, the following categories are forbidden on
company laptops without a Director-level exception:

   - Cryptocurrency miners and wallets
   - Remote-control tools that bypass company SSO (e.g. AnyDesk, TeamViewer
     personal edition; the company-licensed remote-support tool is
     permitted)
   - VPN clients that route corporate traffic outside the company network
   - Pirated, cracked, or activation-bypass software of any kind
   - Browser extensions that read or modify all page content, unless on
     the IT-Approved Catalog

4. Personal devices
This policy applies only to company-owned laptops. BYOD devices accessing
company data via the corporate MDM profile are governed by the BYOD
Acceptable Use Policy (separate document).

5. Violations
Installation of forbidden software is a security incident. Repeated
violations may result in disciplinary action up to and including
termination.
