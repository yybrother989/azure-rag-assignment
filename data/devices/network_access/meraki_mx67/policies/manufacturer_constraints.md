# Meraki MX67 Manufacturer Constraints

## Use boundaries derived from the installation guide
- Use only the unit's intended power supply.
- Complete Dashboard network preparation before going on-site when possible.
- For first-time bring-up, use a working wired Internet connection.
- If cellular hardware is present on supported variants, do not swap or install SIM cards while the unit is powered on.
- If static uplink settings are required, use the local setup page rather than guessing configuration.
- Keep original packaging for warranty / RMA workflows when possible.

## Operational boundaries
These are **manufacturer / installation constraints**, not bank policy:
- do not interrupt firmware upgrades unnecessarily
- do not perform factory reset unless there is a clear reason
- do not assume cellular-first initial bring-up is supported
- do not use non-standard power accessories

## Not covered here
This file does not define:
- internal network change approval
- branch cutover process
- firewall ownership or change windows
- bank-specific escalation or incident policy
