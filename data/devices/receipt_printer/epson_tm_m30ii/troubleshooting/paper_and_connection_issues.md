# Epson TM-m30II Paper and Connection Issues

## Paper not loading or printing correctly
Check:
- roll paper is installed correctly
- paper width setting matches actual paper width
- the roll paper cover is fully closed
- the printer is not offline due to cover-open or paper-end conditions

## Roll paper near-end note
Near-end detection is available only under specific conditions, including front eject setup and 80 mm roll usage.

## Jam / cutter / cover issues
### Cover open error
The printer returns from this error when the roll paper cover is closed.

### Autocutter error
- remove foreign material or jammed paper
- close the roll paper cover to recover

### Unrecoverable errors
If the error persists after power cycling, stop and escalate to qualified service personnel.

## Ethernet / Wi-Fi / Bluetooth connection checks
Use interface and status information to confirm:
- Ethernet link
- Wi-Fi state
- Bluetooth pairing state
- status sheet details if needed

## Network setup reminders
For Ethernet / Wi-Fi:
- EpsonNet Config and EpsonNet Config (Web version) are supported
- a status sheet can be used to confirm interface details
- wireless setup may use SimpleAP defaults on supported Wi-Fi models

## Good operator rule
Start with:
- power
- cover state
- paper state
- interface state
- then reset only if needed through the documented modes
