# Epson TM-m30II Quick Start

## Purpose
Use this guide for first-line setup, power, host connection, and paper handling.

## Basic setup flow
The printer setup flow in the manual includes:
1. install the printer
2. change paper width if needed
3. connect optional components if used
4. connect power
5. connect to host devices
6. attach power switch cover if used
7. enable near-end detection if required

## Key connectors
The printer includes:
- USB Type-A
- power connector
- USB Type-B
- Ethernet
- drawer kick connector

## Power
1. Confirm the printer is off.
2. Connect AC cable to the AC adapter.
3. Connect the adapter to the printer.
4. Plug into mains.
5. Turn on the printer.

## Host connection options
Supported host connection paths include:
- USB
- Ethernet
- wireless LAN
- Bluetooth

## Paper basics
To load paper:
- open the roll paper cover
- install roll paper correctly
- close the cover
- use the Feed button if needed

## Good first checks
If setup is uncertain:
- verify power
- verify interface choice
- verify cable seating
- verify LED state
- verify the printer is online rather than offline
