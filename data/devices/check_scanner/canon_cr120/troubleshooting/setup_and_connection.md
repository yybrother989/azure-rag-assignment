# Canon CR-120 Setup and Connection

## Purpose
Use this guide for first-line setup, USB / LAN connection checks, and power-on validation.

## Setup order
Follow this order:
1. Check operating environment
2. Install software / Scanning Utility
3. Connect the scanner to the computer
4. Turn on the scanner
5. Allow the driver to install automatically

## Important setup rule
Install the Scanning Utility **before** connecting the scanner. If the scanner is connected first, Windows may prompt for hardware installation prematurely.

## Connection types
### USB
- connect type B to the scanner and type A to the computer
- use the provided USB cable or a Hi-Speed USB 2.0 compatible cable

### Ethernet (N models only)
- LAN is available on CR-150N / 120N variants
- confirm the connected computer can reach the network
- network settings vary by environment and may require imageFORMULA Utility or WEB MENU

## Power-on check
- press the power button
- the button should flash slowly and then become solid blue
- if it continues flashing or the scanner does not behave normally, stop and escalate

## Auto power off note
The scanner may power off automatically after 4 hours if the setting remains enabled.

## Fast triage
If the scanner is not recognized:
- confirm Scanning Utility was installed first
- verify cabling
- try another USB port
- reconnect after both computer and scanner are on
- remove incompatible USB hub use if present
