# Canon CR-120 Scan, Feed, and Jam Issues

## Scanner not recognized
Common checks:
- install Scanning Utility before connecting the scanner
- confirm the scanner is correctly connected
- restart the computer
- try a different USB port
- disconnect and reconnect the cable with both devices powered on
- remove unsupported USB hubs

## Network trouble
If network connection fails:
- verify scanner and computer are correctly connected to the network
- verify power to the scanner and network device
- confirm the configured IP address is correct
- if WEB MENU does not load, confirm the IP address again
- if no scanners appear in the specified scanner list, confirm mDNS is enabled where applicable

## Clearing a paper jam
1. Remove documents from the eject pocket.
2. Press and hold the Start button to eject the jammed document.
3. If that does not clear it:
   - open the right maintenance cover
   - open the left maintenance cover
   - remove jammed paper
   - close both covers until they click

## Feeding trouble
Check:
- document size and thickness are within supported range
- rough-surface documents are fed one sheet at a time in Separation OFF mode
- rollers are clean
- worn rollers are replaced
- separation roller gap is not too wide

## Card jam
- open the left maintenance cover
- or press and hold the Start button to eject the jammed card

## MICR not recognized correctly
- clean the MICR magnetic head
